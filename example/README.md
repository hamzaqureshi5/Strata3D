# Example DICOM series

Test data for Strata3D. Open a folder with **File ▸ Open DICOM Folder…**, or start the
app with it: `./build/Strata3D example/<folder>`.

| Folder | What it is | Size |
|---|---|---|
| `downloads/tcga_thca_headneck_ct/` | **Real** head & neck CT (Siemens, 512 x 512 x 148, 0.98 x 0.98 x 1.5 mm, HU). Teeth around slice 81. | 75 MB |
| `dental_ct/` | Synthetic dental phantom, CT-like (HU via RescaleIntercept -1024). | 5 MB |
| `dental_cbct/` | Same phantom, CBCT-like (uncalibrated gray values). | 5 MB |
| `synthetic_ct/` | Simple synthetic CT: torus + sphere. | 3 MB |

## Synthetic phantoms

Generated by `tools/dental_phantom.cpp`, so they can be recreated at any time:

```bash
./build/dental_phantom example/dental_ct
./build/dental_phantom example/dental_cbct --cbct
```

0.5 mm voxels, 160 x 160 x 100. Contents (mm): soft tissue (40 HU) in air, a horseshoe
mandible (900 HU, z 5-25), 12 teeth on the arch (dentin 1700 HU, enamel cap 2500 HU,
z 14-36) and a 2.4 mm nerve canal (30 HU) at z = 11 mm along the arch (radius 27 mm).
Useful for checking results against known geometry.

  rules; keep this repository private or remove the data before making it public.

To download it again (no account needed):

```bash
SERIES=1.3.6.1.4.1.14519.5.2.1.8421.4019.123670597687203511219463516732
curl -o ct.zip "https://services.cancerimagingarchive.net/nbia-api/services/v1/getImage?SeriesInstanceUID=$SERIES"
mkdir -p example/downloads/tcga_thca_headneck_ct && unzip ct.zip -d example/downloads/tcga_thca_headneck_ct
```
